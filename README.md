# 自定义皮肤 · DSH 本地插件
一个可自行设定 DSH Web 背景图片、并调节对比度/亮度/模糊与可读性遮罩的本地皮肤插件。目标：让 DSH WebUI 在任意背景图上依然**美观、可操作、可读**。

---
## 功能
- **自定义背景图片**：本地上传（自动压缩到 ≤1920px 的 JPEG，控制在 localStorage 预算内），或粘贴图片链接（`https://…`、相对路径、`data:image/…`）。
- **图片对比度**：50% – 200%，直接作用于背景图的 CSS `contrast()`。
- **图片亮度**：50% – 150%。
- **图片模糊**：0 – 30px。
- **可读性遮罩**：0 – 100%，在背景图与界面之间铺一层与当前明/暗主题匹配的薄雾，保证文字对比度。
- **界面不透明度**：30% – 100%，控制卡片、菜单、输入框等表面的半透明程度。
- **侧边栏透明度**：0% – 100%，单独控制左侧边栏。`0%` 时侧边栏完全不透明（看不到背景图），`100%` 时完全透明（背景图完全透出）。
- **独立底色（侧边栏 / 对话框）**：侧边栏与对话框可以各自单独选一个底色，并各自单独调节该颜色的不透明度；默认「自动」跟随当前主题，点色块即打开系统全色系调色盘。
  - **「对话框」包含打字输入区**：对话框底色同时作用于弹出面板与底部输入框（composer），所以打字区域和弹窗是一套配色。**设置弹窗除外**——它始终保持主题纯色。
  - **「颜色不透明度」始终生效**：即使底色仍是「自动」，不透明度滑杆也会作用在当前主题色上——设置面板因此可以真正调成半透明，露出背景图。
  - **默认对话框不透明度 78%**：开箱即略带透明，设置面板与弹窗不再像原生那样完全不透明。
  - **「与侧边栏相同」**：打开后，对话框跟随侧边栏的**实际填充**——侧边栏选了自定义色就同步该色与不透明度，没选色就同步「侧边栏透明度」滑杆决定的填充。侧边栏一改，对话框立刻同步。
- **外观自动识别**：根据背景图整体色调自动把 `通用设置 → 外观` 设为浅色或深色（浅色图 → 浅色外观，深色图 → 深色外观），可随时关闭。
- **设置页面不受皮肤影响**：设置弹窗始终保持主题原生纯色（浅色 = 白、深色 = 黑），不被背景图/自定义底色渗透，保证设置项清晰可读；皮肤只作用于主界面、侧边栏、对话框与打字输入区。
- **明/暗主题自适应**：跟随 DSH 原生浅色/深色/跟随系统；主题切换时自动重算表面色。
- **一键恢复默认**：保留背景图，重置所有滤镜与遮罩参数。
- **持久化**：所有设置存于 `localStorage`（`dsh-custom-skin:*`），刷新后保留。

设置入口：`设置 → 左侧「自定义皮肤」`（独立分区，不再放在通用设置里）。

## 安装
> 需要先安装 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（`dsh` CLI）。

### 从本地目录安装（推荐，便于迭代）

```sh
dsh plugin --profile web add /Users/jamesjiang/ds_harness_workspace/dsh-client-custom-skin
```

`dsh plugin` 会把相对/绝对路径解析到**你运行命令的目录**，并以 link 依赖装入 Web profile。改完源码后无需重新安装。

### 验证安装

```sh
dsh --profile web --dump-config | grep -B1 -A2 custom-skin
```

输出中应出现 `dsh-client-custom-skin` 配置层。

### 重启生效

如果 DSH Web 正在运行，重启后才能加载新的客户端插件：

- 在运行 DSH 的终端按 `Ctrl+C`，再运行 `dsh web`（推荐）。
- 重启会中断当前会话，但 DSH 会话有磁盘持久化，重启后可恢复。

### 卸载

```sh
dsh plugin --profile web remove @leon___/dsh-client-custom-skin
```

## 使用

1. 打开 `设置`，在左侧导航点「自定义皮肤」。
2. 点「选择图片」上传本地图片，或在输入框粘贴图片链接后点「应用」。
3. 右上角「启用自定义皮肤」开关控制整体生效；关闭即可回到原生外观。
4. 拖动 **图片对比度 / 图片亮度 / 图片模糊** 调整背景观感。
5. 若文字不够清楚，提高 **可读性遮罩**；若想让界面更透出背景，提高 **界面不透明度** 或降低遮罩。
6. **侧边栏透明度** 单独调节左侧栏：`0%` 让它完全挡住背景图，`100%` 让它完全透明。
7. **独立底色**：在「独立底色」里分别给**侧边栏**和**对话框**选颜色（点色块打开全色系调色盘），再各自拖动「颜色不透明度」；点「自动」可交还给主题。
8. **对话框统一配色**：想省事就打开「与侧边栏相同」——对话框（含打字输入区）的色调与不透明度直接跟侧边栏保持一致。
6. 点「恢复默认」重置滤镜参数（背景图保留）。

### 推荐参数

| 场景 | 对比度 | 亮度 | 模糊 | 遮罩 | 界面不透明度 | 侧边栏透明度 |
| --- | --- | --- | --- | --- | --- | --- |
| 亮色照片、偏白界面 | 100% | 100% | 0px | 55% | 90% | 15% |
| 暗色照片、深色界面 | 110% | 100% | 0px | 50% | 88% | 15% |
| 高细节/杂乱照片 | 90% | 95% | 8px | 65% | 92% | 0% |
| 极简壁纸、想要通透感 | 105% | 100% | 0px | 30% | 78% | 60% |

## 工作原理

- 浏览器半身（`lib/client.js`）在 `apply(ctx)` 中：
  1. 注入作用域 CSS；
  2. 创建固定背景层 `.cs-root`（内含 `.cs-image` 图片层与 `.cs-wash` 可读性遮罩层），`z-index:-1`，位于界面内容之下；
  3. 在 `<body>` 上设置 `data-cs-skin="on"` 与一组 `--cs-*` CSS 变量；
  4. 用 `--dsw-alias-*` 令牌覆盖让外壳背景透明、面板半透明，同时保留原生文字/边框令牌，保证可读性；
  5. 将设置行注册进 `settings.general.item` 槽位；
  6. 监听 `theme/change` 与 `body[data-ds-dark-theme]` 变化，重新推导明/暗两套表面色。
- Host 半身（`src/index.js`）是刻意留空的 no-op：本插件全部工作在浏览器端，设置保存在 `localStorage`（与其它第三方皮肤一致的视觉偏好边界）。

## 本地开发

```sh
cd dsh-client-custom-skin
node smoke-test.mjs   # 模拟 shell 环境，验证 bundle 加载、apply、槽位注册与持久化
```

`smoke-test.mjs` 会用一个最小 DOM / `window.__ModuleLoader__` / 桩 React 运行 `lib/client.js`，并断言背景层、`data-cs-skin`、CSS 变量、设置行与 localStorage 往返都正确。

## 已知限制

- 背景图以 data URL 存入 `localStorage`，浏览器单源预算约 5MB；本插件上传时会自动压缩，通常远低于上限。若手动粘贴超大 data URL 仍可能写入失败（会静默保留旧值）。
- 若同时启用其它皮肤插件（如 dream-skin、liang-skin），`--dsw-alias-*` 令牌可能互相覆盖；请只启用一个皮肤插件。
- 部分自绘原生弹窗（账号页等）可能不完全透出背景图，但始终保持可读。
